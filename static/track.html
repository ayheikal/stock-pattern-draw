How this is measured. At each sample (one per horizon, so windows never overlap) the outlook is rebuilt from the previous 250 bars only, exactly as the live chart would have shown it, then compared with what price did next. The trade plan is checked bar by bar: if target and stop are both touched on the same bar, it counts as a stop. Limits: the watchlist is today's large caps (companies that failed are missing, which flatters results), no fees or slippage, and a past record is no promise about the future.
